## 功能特点

- **增量更新**：每周自动抓取 arXiv 最新论文，跟踪重要模型发布、开源项目与产业动态
- **分类清晰**：覆盖 10 大领域，每领域设论文库、知识库、模型库、代码库、数据集库
- **全文搜索**：快速定位感兴趣的论文
- **趋势追踪**：记录各领域的演进脉络和前沿方向

## 如何使用

1. **浏览领域**：点击顶部导航栏进入具体领域
2. **搜索论文**：使用右上角搜索框
3. **查看更新**：点击"更新日志"查看最新添加的论文
4. **标签过滤**：每篇论文都有标签，可以快速筛选相关研究

## 更新机制

- **更新频率**：每周一次（周一）
- **数据来源**：arXiv、顶会论文、Papers With Code
- **自动筛选**：根据关键词过滤相关论文，涵盖 10 大领域
- **工作流**：新内容先录入 [每周增量更新](categories/weekly-update/index.md)，再归档到对应分支

## 论文格式

每篇论文包含：
- 一句话总结
- 核心思想
- 为什么重要
- 关键实验结果
- 原文链接
