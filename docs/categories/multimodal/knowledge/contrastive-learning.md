# 对比学习 (Contrastive Learning)

## 1. 核心思想

通过拉近正样本对、推远负样本对，学习数据的判别性表示。

## 2. 视觉对比学习

### 2.1 SimCLR

同一图像的两个增强视图作为正样本对。

    L = -log(exp(sim(z_i, z_j)/tau) / sum(exp(sim(z_i, z_k)/tau)))

### 2.2 数据增强

| 增强方法 | 效果 |
|----------|------|
| 随机裁剪 | 最重要 |
| 颜色抖动 | 重要 |
| 高斯模糊 | 重要 |
| 旋转 | 次要 |

## 3. 跨模态对比学习

### 3.1 CLIP

同时训练图像编码器和文本编码器：

- 正样本：匹配的图文对
- 负样本：batch 内不匹配的图文对

    L = -log(exp(sim(img_i, txt_i)/tau) / sum(exp(sim(img_i, txt_j)/tau)))

### 3.2 训练技巧

| 技巧 | 说明 |
|------|------|
| 大 batch | 负样本越多越好 |
| 温度参数 | 通常 0.07 |
| 投影头 | 非线性投影提升效果 |
