# 视觉-语言模型

## 1. 概述

视觉-语言模型 (VLM) 能同时理解和生成文本与图像。

## 2. 架构分类

### 2.1 编码器模型

CLIP：图像编码器 + 文本编码器 + 对比学习

适用：零样本分类、检索

### 2.2 编码器-解码器模型

BLIP-2：图像编码器 + Q-Former + 语言模型

适用：图像描述、视觉问答

### 2.3 指令微调模型

LLaVA：视觉编码器 + 线性投影 + LLM

适用：多模态对话

## 3. 关键组件

| 组件 | 作用 | 代表 |
|------|------|------|
| 视觉编码器 | 提取图像特征 | CLIP ViT, SigLIP |
| 连接器 | 连接视觉和语言 | 线性层, Q-Former, MLP |
| 语言模型 | 理解和生成文本 | LLaMA, Vicuna, Qwen |

## 4. 训练阶段

### 4.1 预训练

在大规模图文对上训练连接器，对齐视觉和语言空间。

### 4.2 指令微调

用图文对话数据微调，提升指令遵循能力。
