# 语音识别基础

## 1. 任务定义

将音频信号转换为文本：Audio -> Text

## 2. 方法演进

| 方法 | 时期 | 特点 |
|------|------|------|
| HMM-GMM | 1980s-2010s | 隐马尔可夫模型 |
| DNN-HMM | 2010s | 深度学习 + HMM |
| CTC | 2015+ | 端到端，无需对齐 |
| Transformer | 2019+ | 自注意力架构 |
| Whisper | 2022 | 大规模弱监督 |

## 3. Whisper 架构

### 3.1 编码器

- 输入：80 维 log-Mel 频谱图
- 架构：标准 Transformer 编码器
- 输出：音频特征序列

### 3.2 解码器

- 输入：音频特征 + 已生成的文本
- 架构：标准 Transformer 解码器
- 输出：下一个 token 的概率

### 3.3 多任务

通过特殊 token 指定任务：

    <|en|> <|transcribe|> <|notimestamps|> Hello world

支持：转录、翻译、语言识别、时间戳

## 4. 评估指标

| 指标 | 说明 |
|------|------|
| WER | 词错误率 |
| CER | 字符错误率 |
| RTF | 实时因子（速度） |
