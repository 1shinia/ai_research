# 跨模态对齐

## 1. 核心问题

如何让不同模态（文本、图像、音频）的信息在同一个表示空间中对齐？

## 2. 对齐方法

### 2.1 双塔架构 (Dual Encoder)

每个模态独立编码，然后在共享空间对齐。

代表：CLIP, Sentence-BERT

优点：高效，支持大规模检索
缺点：无法建模跨模态交互

### 2.2 交叉架构 (Cross Encoder)

将不同模态拼接后联合编码。

代表：ViLBERT, LXMERT

优点：更强的跨模态理解
缺点：计算成本高

### 2.3 线性投影

简单的线性层连接不同模态空间。

代表：LLaVA

优点：简单有效
缺点：表达能力有限

## 3. 对齐评估

| 指标 | 说明 |
|------|------|
| R@K | 检索召回率 |
| CLIP Score | 图文相似度 |
| 人类评估 | 整体质量 |
