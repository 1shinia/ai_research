# 多模态趋势追踪

记录多模态 AI 领域的前沿方向和演进脉络。

## 2026 年趋势

### 🧬 原生多模态模型
- GPT-4o / Gemini 证明原生多模态（而非胶水拼接）是正道
- **统一 Transformer 架构**处理文本 + 图像 + 音频 + 视频
- 多模态大模型的训练范式从"预训练 → 对齐"向"端到端联合训练"演进

### 🎵 音频 + 语音深度融合
- 语音对话延迟降至 200ms 以下，接近人类对话体验
- **语音情感 / 语调 / 副语言信息**成为多模态研究热点
- 音乐理解和生成统一模型出现

### 🖼️ 文档智能 (DocAI)
- VLM 在 PDF / 表格 / 图表 / 公式理解上能力大幅提升
- 多页 PDF 文档推理能力成熟
- **Layout + Text + Image 三模态联合建模**成为标准

### 🌐 多语言多模态
- 非英语多模态能力建设成为重点（多语言 OCR / 多文化视觉理解）
- 多模态评估从英文中心转向多语言覆盖
- 文化特定视觉概念理解仍是挑战

## 2025 年回顾

- **GPT-4o 发布**: 首个原生多模态旗舰模型，语音到语音无中间文本转录
- **Gemini 2.0**: 多模态能力大幅进化，原生图像/音频输出
- **Qwen2-VL**: 开源多模态模型达到闭源水平
- **多模态 Agent 崛起**: 屏幕理解 + GUI 操控成为热门方向

## 前沿方向

- **统一多模态理解与生成**: 一个模型做理解和生成（如 Gemini / Chameleon）
- **多模态推理链**: 结合视觉 + 文本的多步推理
- **具身多模态**: 结合触觉 / 深度 / 力反馈的多模态感知
- **多模态安全性**: 跨模态越狱攻击防御
