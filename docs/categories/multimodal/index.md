# 多模态 (Multimodal)

## 领域概览

多模态研究如何让模型同时理解和生成文本、图像、音频、视频等多种模态的信息。

## 关键研究方向

- **视觉-语言模型**：CLIP、LLaVA、GPT-4V
- **音频-语言模型**：Whisper、AudioLM
- **视频-语言模型**：Video-LLaMA、VideoChat
- **统一架构**：一个模型处理所有模态
- **跨模态对齐**：如何让不同模态的信息相互理解
