## 详情

### 🆕 IA-Bench（智能体图像生成评估）

- **来源**：[Qwen-Image-Agent](https://arxiv.org/abs/2606.26907) 配套基准
- **特点**：评估Agent式T2I的规划、推理、搜索和记忆四大核心能力
- **意义**：首个专门评估"Agent辅助图像生成"的基准，推动T2I从提示词工程向Agent范式转变

### 🆕 REALM（物理世界VLM红队基准）

- **arXiv**：[2606.23892](https://arxiv.org/abs/2606.23892)
- **规模**：集成12种红队方法、3种防御策略、13个VLM模型
- **创新**：代理目标生成管道（Proxy Target Generation Pipeline）确保公平比较
- **关键发现**：文本/字体注入攻击诱导最多失败；模型规模本身不保证对抗鲁棒性
- **开源**：代码已开源

### 🆕 MCPToolBench++（大规模MCP工具调用基准）

- **arXiv**：[2508.07575](https://arxiv.org/abs/2508.07575)
- **规模**：4000+ MCP服务器，40+类别，覆盖单步和多步工具调用
- **意义**：首个大规模MCP工具使用评测基准
- **评估**：系统评估SOTA LLM和AI Agent的MCP工具调用能力

### 🆕 synCUB / synCOCO（SAE可解释性评估）

- **arXiv**：[2606.24716](https://arxiv.org/abs/2606.24716)
- **设计**：配对图像仅在某个属性上不同，用于验证SAE是否能学到有意义的概念
- **配套算法**：FBMP（完全二分匹配追踪）+ TAPAScore（目标属性扰动对齐分数）
- **关键发现**：过大的SAE字典反而降低可解释性
