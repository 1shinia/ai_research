## 精读推荐 Top 3

### 1️⃣ MACU — Multi-Agent Computer Use

**为什么值得精读：** 计算机使用代理（CUA）是当前Agent落地的核心场景，但单代理模式在长时任务中频繁"卡住"。MACU证明了多Agent协调是突破这一瓶颈的有效维度。**重点理解**其管理Agent如何将任务分解为DAG、如何动态修订DAG、子Agent如何并行执行。

**配套实践：** 代码已开源，可用OSWorld基准复现实验。

### 2️⃣ FlexMoE — One-for-All Nested Intra-Expert Pruning

**为什么值得精读：** MoE架构是大模型标配，但部署成本是核心痛点。FlexMoE的"一次训练多预算输出"范式将从根本上改变MoE压缩的工程实践。**重点理解**其通道重要性排序、离散动作学习和恢复微调策略。

**配套实践：** Qwen2-57B-A14B上的实验设计值得参考。

### 3️⃣ Block-GTQ — RoPE-Aware Bit Allocation

**为什么值得精读：** 在极低比特（K2V2、K3V2）下将"不可能"的量化变为可行，理论分析干净利落。**重点理解**RoPE频率块的标签自由能量分数、贪心比特分配流程。

**配套实践：** 代码已开源，可在自己的模型上复现。
