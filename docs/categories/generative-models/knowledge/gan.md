# GAN 原理 (Generative Adversarial Networks)

## 1. 核心思想

通过生成器和判别器的博弈训练，学习数据分布。

    min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]

## 2. 架构

### 2.1 生成器 (Generator)

    G: z -> x_fake

从随机噪声 z 生成假数据。

### 2.2 判别器 (Discriminator)

    D: x -> [0, 1]

判断输入是真实数据还是生成数据。

## 3. 训练过程

1. 训练判别器：让 D 更好地区分真假
2. 训练生成器：让 G 更好地欺骗 D
3. 交替训练，直到纳什均衡

## 4. 变体

| 变体 | 创新 |
|------|------|
| DCGAN | 卷积架构，更稳定 |
| WGAN | Wasserstein 距离，更好训练 |
| StyleGAN | 风格控制，高质量人脸 |
| CycleGAN | 无配对图像翻译 |
| Pix2Pix | 配对图像翻译 |

## 5. 问题与解决

| 问题 | 原因 | 解决 |
|------|------|------|
| 模式坍塌 | G 只生成少数模式 | WGAN, 多样性正则 |
| 训练不稳定 | 梯度消失/爆炸 | 谱归一化, 梯度惩罚 |
| 评估困难 | 没有统一指标 | FID, IS |
