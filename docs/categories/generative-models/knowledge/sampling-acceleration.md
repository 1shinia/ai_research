# 采样加速

## 1. 问题

扩散模型需要 1000 步采样，速度慢。

## 2. 加速方法

### 2.1 少步采样

| 方法 | 步数 | 原理 |
|------|------|------|
| DDIM | 50-100 | 确定性 ODE |
| DPM-Solver | 10-20 | 高阶 ODE 求解器 |
| 一致性模型 | 1-4 | 蒸馏 |

### 2.2 蒸馏

用教师模型指导学生模型：

    教师 (1000 步) -> 学生 (4 步)

### 2.3 渐进蒸馏

逐步减少步数：

    1000 -> 500 -> 250 -> 125 -> ...

## 3. 对比

| 方法 | 步数 | 质量 | 训练成本 |
|------|------|------|----------|
| DDPM | 1000 | 最好 | 无 |
| DDIM | 50 | 好 | 无 |
| DPM-Solver | 20 | 好 | 无 |
| 一致性模型 | 4 | 中 | 高 |
