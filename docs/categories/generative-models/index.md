# 生成式模型 (Generative Models)

## 领域概览

生成式模型致力于让 AI 创造新的内容，包括图像、文本、音频、视频、3D 场景等。这是当前 AI 应用最广泛的领域之一。

## 关键研究方向

- **扩散模型 (Diffusion)**：DDPM、Score-based、Flow Matching
- **生成对抗网络 (GAN)**：StyleGAN、BigGAN、CycleGAN
- **变分自编码器 (VAE)**：VQ-VAE、dVAE
- **自回归生成**：GPT 系列、PixelRNN
- **统一生成架构**：一个模型生成多种模态
