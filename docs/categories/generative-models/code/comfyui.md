## 简介

ComfyUI 是基于节点的 AI 图像/视频生成工具。通过拖拽节点构建工作流，支持 SD / Flux / Stable Video Diffusion / AnimateDiff 等。节点式设计让每一步处理都可视化可控，是专业用户的首选生成工具。

## 核心功能

- 节点式可视化工作流编辑
- 支持 SD / SD3 / Flux / SVD / AnimateDiff 等
- LoRA / ControlNet / IP-Adapter 完整支持
- 工作流可导出分享（.json / .png 嵌入）
- 丰富的社区自定义节点生态

## 快速开始
