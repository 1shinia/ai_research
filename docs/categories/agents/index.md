# AI Agent

## 领域概览

AI Agent 研究如何让大模型具备自主规划、工具使用、环境交互的能力，完成复杂任务。

## 关键研究方向

- **规划与推理**：Chain-of-Thought、Tree-of-Thought
- **工具使用**：函数调用、API 集成
- **记忆机制**：短期记忆、长期记忆、向量数据库
- **多 Agent 协作**：Agent 之间的通信与协作
- **环境交互**：与真实世界或虚拟环境的交互
