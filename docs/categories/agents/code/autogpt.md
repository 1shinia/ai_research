AutoGPT 是早期最具影响力的自主 AI Agent 项目。将 LLM 与互联网搜索、文件操作、代码执行等工具结合，通过 Agent 循环实现自主任务规划和执行。推动了 LLM Agent 范式的社区探索。

## 核心功能

- 自主任务分解和执行
- 互联网搜索和信息获取

- 代码生成和执行
