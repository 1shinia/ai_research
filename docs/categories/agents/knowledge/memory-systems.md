# 记忆机制

## 1. 概述

Agent 需要记忆来保持上下文连贯和学习历史经验。

## 2. 记忆类型

### 2.1 短期记忆 (Working Memory)

当前对话的上下文窗口，有限容量。

    容量：模型的上下文长度（如 4K, 32K, 128K tokens）
    特点：自动管理，无需额外机制

### 2.2 长期记忆 (Long-term Memory)

持久化存储，可以跨会话访问。

    存储：向量数据库、文件系统
    检索：语义搜索、时间过滤
    更新：增量更新、定期压缩

### 2.3 情景记忆 (Episodic Memory)

记录具体事件和经历。

    格式：(时间, 事件, 上下文, 结果)
    用途：从历史经验中学习

## 3. 记忆管理

### 3.1 记忆写入

    memory.add(event="用户喜欢猫", timestamp="2026-06-22", context="对话中")

### 3.2 记忆检索

    results = memory.search(query="用户的宠物偏好", top_k=5)

### 3.3 记忆压缩

当记忆过多时，压缩或遗忘不重要的记忆。

## 4. 实现技术

| 技术 | 说明 | 代表 |
|------|------|------|
| 向量数据库 | 语义检索 | FAISS, Pinecone |
| 摘要 | 压缩长文本 | LLM 摘要 |
| 时间衰减 | 遗忘旧记忆 | 指数衰减 |
| 重要性评分 | 保留重要记忆 | 启发式规则 |
