## 一句话总结

将推理（Reasoning）和行动（Acting）交替进行，让大模型在执行任务时既能思考又能使用工具。

## 核心思想

- **交替推理与行动**：Thought → Action → Observation → Thought → ...
- **思维链 + 工具调用**：每一步先推理"我应该做什么"，再执行动作
- **可解释性**：推理过程显式可见，便于调试
- **通用框架**：适用于问答、事实核查、决策等多种任务

## 为什么重要

- 开创了 Agent 的核心范式
- 成为后续 Agent 框架（AutoGPT、LangChain 等）的基础
- 证明了推理和行动的结合优于单独使用
- 为复杂任务的多步规划提供了解决方案

## 关键实验结果

| 任务 | ReAct | CoT | Act Only |
|------|-------|-----|----------|
| HotpotQA | 56.6% | 44.3% | 42.8% |
| FEVER | 78.3% | 63.2% | 54.1% |
| ALFWorld | 75% | 26% | 45% |
