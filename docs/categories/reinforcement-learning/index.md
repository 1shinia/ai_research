# 强化学习 (Reinforcement Learning)

## 领域概览

强化学习研究智能体如何通过与环境交互来学习最优策略，在 LLM 对齐、游戏、机器人等领域有广泛应用。

## 关键研究方向

- **LLM 对齐**：RLHF、DPO、PPO
- **多智能体强化学习**：MARL
- **离线强化学习**：从静态数据中学习
- **模型预测控制**：MPC
- **逆强化学习**：从专家演示中学习奖励函数
