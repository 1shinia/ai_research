## 一句话总结

首次系统性地用人类偏好训练强化学习奖励模型，开创了 RLHF 技术路线，是 ChatGPT 的理论源头。

## 核心思想

- **偏好学习**：让人类比较两个轨迹的优劣，而非直接打分
- **奖励模型**：从偏好数据中学习一个奖励函数
- **主动学习**：智能选择人类需要标注的轨迹对
- **迭代训练**：交替训练策略和奖励模型

## 为什么重要

- 开创了 RLHF 范式
- 证明了人类偏好可以有效指导 RL 训练
- 直接影响了 InstructGPT、ChatGPT 的技术路线
- 为 LLM 对齐提供了实用方案

## 关键实验结果

- Atari 游戏中，用少量人类偏好达到了超人水平
- 在简单机器人任务上，成功学习复杂目标
- 标注效率远高于人工直接打分
