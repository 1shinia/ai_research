# 价值函数

## 1. 状态价值函数 V(s)

从状态 s 开始，遵循策略 pi 的期望回报：

    V^pi(s) = E_pi[G_t | S_t = s]

## 2. 动作价值函数 Q(s,a)

在状态 s 执行动作 a，之后遵循策略 pi 的期望回报：

    Q^pi(s,a) = E_pi[G_t | S_t = s, A_t = a]

## 3. 最优价值函数

### 3.1 最优状态价值

    V*(s) = max_pi V^pi(s)

### 3.2 最优动作价值

    Q*(s,a) = max_pi Q^pi(s,a)

最优策略：pi*(s) = argmax_a Q*(s,a)

## 4. 估计方法

| 方法 | 说明 | 代表算法 |
|------|------|----------|
| 蒙特卡洛 | 完整回合回报 | MC |
| 时序差分 | 一步更新 | TD(0), SARSA |
| n-step | n 步更新 | n-step TD |
| 函数近似 | 神经网络 | DQN, PPO |

## 5. 优势函数 A(s,a)

动作 a 相对于平均动作的优势：

    A(s,a) = Q(s,a) - V(s)

正优势：好于平均
负优势：差于平均
