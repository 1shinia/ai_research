# 马尔可夫决策过程 (MDP)

## 1. 定义

MDP 是强化学习问题的数学框架，由五元组定义：

    MDP = (S, A, P, R, gamma)

| 符号 | 含义 |
|------|------|
| S | 状态空间 |
| A | 动作空间 |
| P(s'|s,a) | 状态转移概率 |
| R(s,a) | 奖励函数 |
| gamma | 折扣因子 (0-1) |

## 2. 马尔可夫性质

未来状态只依赖当前状态，与历史无关：

    P(s_{t+1} | s_t, a_t, s_{t-1}, ..., s_0) = P(s_{t+1} | s_t, a_t)

## 3. 策略

### 3.1 确定性策略

    a = pi(s)

### 3.2 随机策略

    pi(a|s) = P(A_t = a | S_t = s)

## 4. 回报

### 4.1 累积回报

    G_t = R_{t+1} + gamma * R_{t+2} + gamma^2 * R_{t+3} + ...

### 4.2 折扣因子

- gamma = 0: 只看即时奖励
- gamma = 1: 未来奖励与当前同等重要
- gamma -> 1: 更重视长期

## 5. 贝尔曼方程

### 5.1 状态价值

    V(s) = E[R + gamma * V(s')]

### 5.2 动作价值

    Q(s,a) = E[R + gamma * max_a' Q(s',a')]
