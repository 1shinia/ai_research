# 计算机视觉 (Vision)

## 领域概览

计算机视觉致力于让机器"看懂"图像和视频，涵盖检测、分割、生成、理解等任务。

## 关键研究方向

- **目标检测**：YOLO 系列、DETR 系列
- **图像分割**：SAM、Mask2Former
- **图像生成**：扩散模型、GAN
- **视频理解**：时序建模、动作识别
- **3D 视觉**：NeRF、3D Gaussian Splatting
