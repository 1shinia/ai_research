# 图像分割

## 1. 任务类型

| 类型 | 说明 | 粒度 |
|------|------|------|
| 语义分割 | 每个像素的类别 | 类别级 |
| 实例分割 | 每个像素的实例 ID | 实例级 |
| 全景分割 | 语义 + 实例 | 最细 |
| 交互式分割 | 用户指定要分割的对象 | 用户引导 |

## 2. 方法演进

### 2.1 语义分割

FCN -> U-Net -> DeepLab -> SegFormer

### 2.2 实例分割

Mask R-CNN -> Mask2Former -> YOLACT

### 2.3 交互式分割

SAM (Segment Anything) 开创了通用分割基础模型。

## 3. SAM 架构

```
图像 -> 图像编码器 (ViT) -> 图像嵌入
                                |
提示 (点/框) -> 提示编码器 -> 提示嵌入
                                |
                    掩码解码器 -> 掩码 + IoU 分数
```

## 4. 评估指标

| 指标 | 说明 |
|------|------|
| mIoU | 平均交并比 |
| AP | 平均精度 |
| SAM 质量 | IoU + 边界质量 |
