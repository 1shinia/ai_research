# 卷积神经网络 (CNN)

## 1. 核心思想

通过局部连接和权值共享，自动学习图像的空间层次特征。

## 2. 核心组件

### 2.1 卷积层

    output[i,j] = sum(W * input[i:i+k, j:j+k]) + b

- 局部连接：每个输出只依赖局部区域
- 权值共享：同一滤波器在所有位置共享
- 平移等变：物体移动不影响特征响应

### 2.2 池化层

| 类型 | 公式 | 作用 |
|------|------|------|
| 最大池化 | max(window) | 保留最强特征 |
| 平均池化 | mean(window) | 平滑特征 |
| 全局平均池化 | mean(all) | 替代全连接层 |

### 2.3 感受野

感受野 = 输入图像中影响某个输出的区域大小。

随着层数增加，感受野指数增长，使深层能捕获全局信息。

## 3. 经典架构

| 模型 | 年份 | 创新点 |
|------|------|--------|
| LeNet | 1998 | 第一个成功的 CNN |
| AlexNet | 2012 | 深度学习复兴 |
| VGGNet | 2014 | 小卷积核堆叠 |
| GoogLeNet | 2014 | Inception 模块 |
| ResNet | 2015 | 残差连接 |
| EfficientNet | 2019 | 复合缩放 |
