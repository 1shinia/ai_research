## 简介

ImageNet 是 CV 领域最具影响力的图像数据集。ILSVRC 竞赛使用的 ImageNet-1K 含 1.2M 训练图像 / 1000 个类别。推动了 AlexNet / ResNet / ViT 等革命性架构的出现。

## 核心特点

- 最大规模的通用图像分类基准
- 标准化的 Train/Val/Test 划分
- 层次化类别结构（WordNet）

## 典型用途

- 图像分类基准
- 预训练和迁移学习
- 模型架构创新验证
