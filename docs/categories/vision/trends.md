# 计算机视觉趋势追踪

记录计算机视觉领域的前沿方向和演进脉络。

## 2026 年趋势

### 🧠 视觉自回归模型
- GPT-4o / Gemini 验证了多模态自回归的可行性
- **ViT + 自回归 + 扩散混合架构**成为视觉生成新范式
- 视觉 Tokenizer 质量成为关键瓶颈（Chameleon / SEED 等技术）

### 📐 4D / 空间智能
- 从 2D 视觉向 3D / 4D（3D+时间）空间智能全面进发
- Gaussian Splatting 衍生技术大量涌现：Mip-Splatting / 4D-GS
- 世界模型 (World Model) 与视觉结合，学习物理规律表达

### 🔍 视觉基础模型 (VFM)
- DINOv2 / SAM2 / DETR 系列持续扩展
- **通用视觉模型**覆盖检测 / 分割 / 深度 / 法线等所有任务
- 视觉与语言的对齐技术（SigLIP / CLIP）仍在进化

### ⚡ 视频理解与生成
- 视频生成（Sora / Kling / Vidu）从演示走向实用
- 长视频理解（逐帧分析 + 时序建模）成为热点
- 视频 Tokenization 和高效时空压缩技术突破
