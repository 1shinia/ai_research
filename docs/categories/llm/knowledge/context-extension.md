# 上下文扩展技术

## 1. 问题

大模型训练时通常使用固定长度（如 4096），但实际应用需要更长的上下文（如 32K、128K）。

## 2. 主要方法

### 2.1 位置插值 (Position Interpolation, PI)

将长序列的位置索引缩放回训练长度范围：

    pos_new = pos * (L_train / L_target)

优点：简单，无需额外训练
缺点：分辨率降低

### 2.2 NTK-aware 缩放

对不同频率维度采用不同缩放策略：

- 高频维度：保持不变（短距离信息不受影响）
- 低频维度：插值（长距离信息需要调整）

### 2.3 YaRN

结合插值和外推，动态调整不同频率的缩放比例。

### 2.4 长上下文微调

用长序列数据直接微调模型：

- 数据：收集或合成长文本
- 方法：渐进式扩展（4K -> 8K -> 16K -> 32K）
- 成本：比预训练高得多

## 3. 对比

| 方法 | 训练成本 | 效果 | 外推性 |
|------|----------|------|--------|
| PI | 无 | 中 | 好 |
| NTK | 无 | 好 | 中 |
| YaRN | 无 | 好 | 好 |
| 长上下文微调 | 高 | 最好 | 最好 |

## 4. 评估

- **大海捞针 (Needle in a Haystack)：** 在长文本中插入关键信息，测试模型能否找到
- **长文档问答：** 在长文档上回答细节问题
- **困惑度：** 在长文本上的语言建模能力
