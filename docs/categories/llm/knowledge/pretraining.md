# 预训练 (Pre-training)

## 1. 概述

预训练是在大规模无标注文本上训练语言模型，学习语言的统计规律和世界知识。

### 1.1 训练目标

自回归语言模型 (GPT 系列)：预测下一个 token

    L = -sum(log P(y_t | y_1, ..., y_{t-1}))

## 2. 数据工程

### 2.1 数据源

| 来源 | 规模 | 质量 |
|------|------|------|
| CommonCrawl | 数万亿 token | 中，需清洗 |
| Wikipedia | ~40 亿 token | 高 |
| 书籍 | 数千亿 token | 高 |
| 代码 (GitHub) | 数千亿 token | 高 |
| 学术论文 | 数百亿 token | 高 |

### 2.2 数据处理流水线

原始数据 -> 语言检测 -> 去重 -> 质量过滤 -> 敏感内容过滤 -> 分词 -> 混合

### 2.3 数据混合

| 来源 | 典型比例 | 作用 |
|------|----------|------|
| 网页 | 60-70% | 通用知识 |
| 书籍 | 10-15% | 长文本理解 |
| 代码 | 5-15% | 逻辑推理 |
| 学术 | 2-5% | 科学知识 |

## 3. 训练策略

### 3.1 学习率调度

余弦退火：先线性预热 2000 步，然后余弦衰减

### 3.2 混合精度

- FP16/BF16 前向 + 反向
- FP32 主权重
- BF16 比 FP16 更稳定

## 4. 基础设施

### 4.1 分布式训练策略

| 策略 | 说明 | 适用 |
|------|------|------|
| 数据并行 (DP) | 每张 GPU 完整模型副本 | 小模型 |
| ZeRO | 分片优化器状态 | 中大模型 |
| 张量并行 (TP) | 分割单个层 | 大模型 |
| 流水线并行 (PP) | 分割不同层 | 超深模型 |

### 4.2 典型训练成本

| 模型 | GPU | 时间 | 成本估算 |
|------|-----|------|----------|
| 7B | 2048 A100 | ~1 周 | ~$100K |
| 70B | 2048 A100 | ~2 月 | ~$2M |
| GPT-4 | 25K A100 | 90+ 天 | ~$100M |
