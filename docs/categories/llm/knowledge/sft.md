# 监督微调 (Supervised Fine-Tuning, SFT)

## 1. 核心思想

在预训练模型基础上，用标注的指令-回答对微调模型，使其学会遵循指令。

训练目标是标准语言建模损失，但**只在回答部分计算损失**。

## 2. 数据格式

常见格式包括 Alpaca 格式（Instruction/Response）和 ChatML 格式（system/user/assistant 消息）。

## 3. 关键技巧

| 技巧 | 说明 |
|------|------|
| 数据质量 > 数量 | 1000 条高质量数据可超过 10 万条低质量 |
| 学习率 | 通常 1e-5 到 5e-5，比预训练小 |
| Epoch 数 | 2-5 轮，太多容易过拟合 |
| 混合数据 | 多种任务混合，防止任务遗忘 |

## 4. 训练流程

1. 准备指令-回答对数据
2. 格式化（加模板）
3. 微调（只训练回答部分的 loss）
4. 评估（人工评估 + 自动指标）

## 5. 数据质量

### 高质量数据特征

- 回答完整、准确
- 遵循指令的所有约束
- 格式规范
- 无有害内容

### 数据来源

| 来源 | 优点 | 缺点 |
|------|------|------|
| 人工标注 | 质量最高 | 成本高 |
| GPT-4 生成 | 成本低 | 可能有偏差 |
| 开源数据集 | 免费 | 质量参差 |
| 混合 | 平衡 | 需要清洗 |
