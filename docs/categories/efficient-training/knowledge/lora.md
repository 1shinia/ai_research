# LoRA 低秩适配 (Low-Rank Adaptation)

## 1. 核心思想

用低秩矩阵分解近似权重更新，大幅减少可训练参数。

    W' = W + Delta W = W + B * A

其中 A in R^{d x r}, B in R^{r x d}, r << d

## 2. 原理

### 2.1 低秩假设

模型适应新任务时，权重更新矩阵 Delta W 具有低秩特性。

### 2.2 参数量对比

| 方法 | 可训练参数 |
|------|-----------|
| 全量微调 | d * d |
| LoRA (r=8) | d * r + r * d = 2 * d * r |
| 比例 | 2r/d |

例如 d=4096, r=8: 参数量只有全量的 0.4%

## 3. 实现

### 3.1 训练时

冻结原始权重 W，只训练 A 和 B：

    output = W*x + (B*A)*x

### 3.2 推理时

合并回原始权重：

    W_merged = W + B*A

零额外推理延迟。

## 4. 变体

| 变体 | 创新 |
|------|------|
| QLoRA | 量化基础模型 + LoRA |
| DoRA | 分解幅度和方向 |
| rsLoRA | 缩放因子修正 |
| LoRA+ | 不同学习率给 A 和 B |

## 5. 超参数

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| r (秩) | 8-64 | 越大容量越高 |
| alpha | 2*r | 缩放因子 |
| 目标层 | Q, K, V, O | 注意力层 |
| dropout | 0.05 | 防止过拟合 |
