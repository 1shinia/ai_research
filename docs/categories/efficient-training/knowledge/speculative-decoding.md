# 推测性解码 (Speculative Decoding)

## 1. 核心思想

用小模型（草稿模型）快速生成多个候选 token，用大模型并行验证。

## 2. 流程

1. 小模型生成 K 个候选 token
2. 大模型并行验证这 K 个 token
3. 接受正确的，拒绝错误的
4. 从拒绝位置重新开始

## 3. 数学保证

推测性解码的输出分布与只用大模型完全一致。

### 3.1 接受概率

    P(accept) = min(1, p_large(x) / p_small(x))

## 4. 效果

| 指标 | 标准解码 | 推测性解码 |
|------|----------|-----------|
| 速度 | 基线 | 2-3x |
| 质量 | 精确 | 精确 |
| 显存 | 大模型 | 大模型 + 小模型 |

## 5. 适用场景

- 小模型与大模型分布相似
- 生成任务有一定的可预测性
- 需要低延迟
