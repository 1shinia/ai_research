# PagedAttention (vLLM)

## 1. 问题

传统 KV Cache 需要预分配连续内存，导致大量内存碎片。

## 2. 核心思想

借鉴操作系统的分页内存管理，将 KV Cache 分成固定大小的块。

### 2.1 传统方式

    预分配最大长度 -> 实际使用率低 -> 内存浪费

### 2.2 PagedAttention

    按需分配块 -> 块表映射 -> 零碎片

## 3. 架构

### 3.1 块 (Block)

固定大小的 KV Cache 单元（如 16 个 token）。

### 3.2 块表 (Block Table)

逻辑块到物理块的映射表。

    逻辑块 0 -> 物理块 42
    逻辑块 1 -> 物理块 17
    逻辑块 2 -> 物理块 89

## 4. 优势

| 优势 | 说明 |
|------|------|
| 零碎片 | 按需分配，不浪费 |
| 共享 | beam search 可共享 KV Cache |
| 高效 | 内存利用率 > 90% |

## 5. 效果

| 指标 | HuggingFace | vLLM |
|------|-------------|------|
| 吞吐量 | 基线 | 2-4x |
| 内存利用率 | 20-40% | > 90% |
