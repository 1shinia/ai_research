## ⭐ 本周高影响力论文精选

### 1. GRPO, Dr. GRPO, and DAPO — 三个方法同一个核心
**领域：强化学习**
揭示 GRPO、Dr. GRPO、DAPO 本质上都在调节同一个数——组内回答的标准差，用群体标准差恒等式统一理解三种方法。

### 2. Decodable Is Not Grounded — VLM 空间推理的虚假接地
**领域：多模态**
通过"灰色空白图"因果控制实验，揭示线性探针和干预恢复会系统性高估 VLM 真正基于图像的程度，标准方法在空间推理上存在隐蔽错误。

### 3. Human-as-Humanoid — 从人类视频零样本学做人形机器人技能
**领域：机器人与具身智能**
利用人类第一人称和第三人称视频，通过人类对齐的具身设定（双摄像头仿人配置）实现零样本人形机器人学习，无需任何机器人演示数据。

### 4. GSRQ — 亚 1-bit KV Cache 量化
**领域：高效训练与推理**
采用增益-形状残差量化（GSRQ），用 4 个 2-bit 码本实现平均约 0.82 bit/dim 的 KV Cache 存储，逼近无损精度。

### 5. The risk of KV cache compression — 缓存压缩的理论风险
**领域：高效训练与推理**
从理论上证明：在软注意力下，仅凭注意力分数无法区分哪些 Token 可以安全丢弃，KV 压缩在某些情况下可能不可避免出错。

### 6. Expander Sparse Autoencoders — 参数高效的 SAE
**领域：AI安全与对齐**
借鉴压缩感知理论，用扩展矩阵 + 稀疏编码显著减少 SAE 参数量，在保持扩展性的同时大幅降低存储开销。

### 7. Infinite Agentic Loops — LLM 代理的无限循环
**领域：大语言模型 / AI Agent**
系统研究 LLM Agent 在执行任务时陷入无限循环的问题，揭示循环模式并提出根本原因分析和缓解方案。

### 8. Ink3D — 用视频生成模型雕琢 3D 资产
**领域：生成式模型**
利用大规模视频生成模型先验，将 3D 生成与视频生成桥接，生成具有极其复杂纹理的 3D 资产。

### 9. Governance Gaps in Agent Protocols — 代理互操作协议的治理缺失
**领域：AI Agent**
系统分析 MCP、A2A、ACP 等代理协议在身份、能力发现、工具访问等方面的治理缺口。

### 10. MoHallBench — 视频 LLM 运动幻觉基准
**领域：AI安全与对齐**
首个系统诊断视频 LLM 运动幻觉的基准，揭示模型会"脑补"视频中不存在的动作。
